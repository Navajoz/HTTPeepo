# HTTPeepo 🐸
An HTTP status code reference inspired by HTTP cats - showcasing responses using 7TV/Twitch emotes. 

![image](https://github.com/user-attachments/assets/ab54b1c1-96b2-4662-afe4-f3c112b334cc)

## 🛠 Tech Stack
- **Frontend**: React + Vite + Tailwind CSS
- **Backend**: Supabase (PostgreSQL)
- **Emote Source**: 7TV/Twitch API

Check out the live version at: https://httpeeepo.vercel.app
