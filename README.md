# HTTPeepo 🐸
An HTTP status code reference inspired by HTTP cats - showcasing responses using 7TV/Twitch emotes. 

![image](https://github.com/user-attachments/assets/757d03e1-40df-42c8-8196-68701702f3d8)

## 🛠 Tech Stack
- **Frontend**: React + Vite + Tailwind CSS
- **Backend**: Supabase (PostgreSQL)
- **Emote Source**: 7TV

🌐 Live Demo: https://httpeepo.vercel.app/
